# mugsun/.github

mugsun 各个公开仓库共用的贡献指南、安全政策和 Issue 模板。

某个仓库自己没有同名文件时，GitHub 会使用这里的版本。仓库自己有的，以仓库里的为准。

| 文件 | 内容 |
| --- | --- |
| [CONTRIBUTING.md](./CONTRIBUTING.md) | 贡献指南，说明怎样提 Issue 和 Pull Request |
| [CONTRIBUTING_EN.md](./CONTRIBUTING_EN.md) | 贡献指南的英文短版 |
| [SECURITY.md](./SECURITY.md) | 怎样私下报告安全问题 |
| [PULL_REQUEST_TEMPLATE.md](./PULL_REQUEST_TEMPLATE.md) | Pull Request 模板 |
| [ISSUE_TEMPLATE/](./ISSUE_TEMPLATE/) | 缺陷报告和功能建议的 Issue 模板 |
| [profile/README.md](./profile/README.md) | mugsun 的简介和仓库列表 |

使用和部署方面的问题，请先查[文档站](https://docs.mugsun.com/)。

## 许可

本仓库只有文档和模板。各产品仓库的许可见它们自己的 `LICENSE`。
