# Contributing

Thanks for contributing to mugsun. This is a short English companion to the Chinese primary guide: [CONTRIBUTING.md](./CONTRIBUTING.md).

## Before you start

1. Read the target repo `README` and [docs.mugsun.com](https://docs.mugsun.com/)
2. Search existing Issues / PRs
3. Open an Issue first for large or breaking changes

## Conventions

- **Commits**: [Conventional Commits](https://www.conventionalcommits.org/); English `type`/`scope`, **Chinese subject** preferred (match `.github/COMMIT_CONVENTION.md` when present). No emoji.
- **Style**: Follow existing formatting and CI; avoid drive-by reformatting.
- **Tests**: Run what you can locally; add coverage for new behavior.
- **Docs**: Update README or docs when user-visible behavior changes.

## Issues & PRs

Use the provided templates. Do **not** open public Issues for security vulnerabilities — see [SECURITY.md](./SECURITY.md).

Keep PRs focused, describe breaking changes and migrations, and wait for CI before review.
